# On-site blog articles

Put one Markdown file per article here, named `<slug>.md`, and add a matching
entry with `slug: "<slug>"` to `BLOG_POSTS` in `src/content/resources.ts`.
The article is then published at `/resources/<slug>`.

No articles are published on-site yet: the live NeuSix site links every blog
card to an external Google Doc, so none were copied here (nothing is invented).
